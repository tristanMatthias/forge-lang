### Skills to Know About
- `/remote-control` — most-used skill on this project; lets Claude drive long-running work remotely
- `/loop` — run a prompt or slash command on a recurring interval; great for "keep running the test suite" or "babysit this build" while you do other work
- `/clear` — reset the conversation when context gets stale (after big refactors or once a ticket is done)
- `/permissions` — manage which tools Claude can run without asking; tune this so trusted commands (make, bd, git status) stop prompting
- `/resume` — pick up a previous Claude Code session
- `/stats` and `/usage` — check how much you've used Claude and what it cost
- `/schedule` — set up cron-style recurring agents (used occasionally for automated checks)
